# ☕ Butter & Bean

A creative and modern café website built with Angular.

## ✨ Features

- Responsive café website
- Modern and creative UI
- Hot Drinks section
- Cold Drinks section
- Donuts section
- Pastries section
- Product search
- Add to Cart
- Increase / decrease product quantity
- Cart page
- Checkout popup
- Login & Signup
- User Profile
- Logout
- Dark Mode
- Not Found page
- Smooth animations
- LocalStorage for cart and user data

## 🛠️ Technologies

- Angular
- TypeScript
- HTML
- SCSS
- Font Awesome
- LocalStorage
